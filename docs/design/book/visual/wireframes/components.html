Components: anatomy, states, rules

The parts every screen is built from. Each has anatomy, states, size rules, behaviour, accessibility and the tokens it may use. No component fixes a colour, a face or a corner shape.

How to read a component

Every block has the same fields so an agent can find what it needs. Sizes are rules in points, not pixels for one device. Colours are grey because colour is pending; roles are named in Tokens.

FieldMeaning
AnatomyParts, in order
Variants and statesEvery state must exist before the component is done
SizeRule with a range or a minimum
BehaviourWhat input does
A11yNames, roles, focus
TokensRoles the component may use; nothing else
DataWire fields it shows (see the position model); the client formats nothing it computes

Font independence. No component sizes itself to a measured string or to one face. Widths come from the grid or from content, text never has a fixed height, and every row has a stacked layout for large text. The typeface will change; see Foundations.

Definition of done. A component is done when every listed state renders, every listed token is used and no other value is, it passes the accessibility row, and its reduced-motion version exists.

Position row

Anatomy
Token pair, pair name and fee and chain line, value with the principal token amounts beside it, owed fees line, range bar. Status chip is hidden on phone and replaced by the bar shape.
Variants
Default, selected (expanded layouts), partial value (adds a text note), spam-hidden (not shown).
States
Default, pressed, focused, selected, loading (skeleton), out of range, stale.

Position card

gridall clientsCards view
Anatomy
Top: pair, status chip. Middle: pair name, meta. Hero value. Bottom: amounts and range bar.
Fill
Card takes one of the four Fills by index modulo 4; ink is chosen by contrast.
States
Default, hover (peek of owed fees), open, focused, loading, out of range.
Size
Width fluid from 260 up; height content-driven, minimum 340 on web. Cards form a grid that wraps into rows, columns at least 260 wide; one column on a phone.
Behaviour
Web: hover only hints (peek of owed fees); click or Enter opens details in place with the Drawer (the face slides up and uncovers the details); an explicit Open link goes to the position page. Touch: tap opens a bottom sheet. Disclosure uses a real button with aria-expanded.
A11y
The card is an article with one button as the hit area. Hidden details are inert while closed. Escape closes and returns focus.
Tokens
color.fill-1 to color.fill-4, color.on-fill-1 to color.on-fill-4, radius.lg, space.inset.md, elevation.level1 intent

Range bar

dataevery screen
Anatomy
Track, band (the position range), marker (current price), two end labels. Optional current price label on the position screen.
Position
Marker position is the server value barPosition in tick space (0 to 1). The client never computes it.
States
In range: marker is a circle inside the band. Out of range: marker changes shape and sits outside the band. Unknown: dashed track, no marker.
Rules
Shape changes with status, so colour is never the only cue. All parts need 3:1 against the surface or fill under them.
Motion
Marker follows the value with the gentle spring; under reduced motion it jumps.
A11y
One image with text: status, quote token price, range low and high. Updated in place, not re-announced on every tick; a status change is announced once.
Tokens
radius.full Colours are the ink of the surface it sits on: color.on-fill-N on a card, color.on-surface on a row.
Data
range.lower range.upper range.current range.barPosition range.status

Status chip

labelword + shape
Anatomy
Shape marker (dot for in range, diamond for out) and a word.
Variants
in-range out-of-range partial-value unlisted paused stale. Unlisted marks a non-default token.
Size
Height 28. Never truncated; wraps to a second line before it is cut.
Rules
Always a word and a shape. A small decorative tilt is design, not structure.
A11y
The text is the accessible name; the shape is hidden from the screen reader.
Tokens
color.surface-container-high color.on-surface color.warning-container color.on-warning-container color.error-container color.on-error-container radius.full font.role.label

Size

Fallback
Monogram of up to 3 characters on a token-derived tone, plus the chain badge. A missing logo never leaves a hole.

Value

texttabular
Anatomy
Currency mark, whole part, optional decimals, optional note ("est.", "partial").
Roles
By place: hero total display-lg, card value display-md, row value display-sm, amounts body with tabular digits.
Rules
Tabular digits. Value comes formatted from the server; the client only places it. An unpriced value is never shown as zero; it shows the amount or "n/a".
Motion
A changed value rolls its digits in the direction of change; reduced motion swaps the text.
A11y
Plain text. Live updates change in place; no live-region announcement per tick.
Tokens
font.role.display-* font.feature.tabular-nums color.on-surface

Button

controlprimary secondary tertiary destructive
Variants
primary secondary tertiary destructive. One primary per screen region.
Size
Height 56 for the main action, 48 default, 40 compact. Width: full in a sheet or on phone, auto elsewhere with a 120 minimum. Hit area never below 44.
States
Default, hover, pressed, focused, disabled, busy (spinner replaces label, width kept).
Rules
Label says what happens (verb). Disabled still shows why in nearby text.
A11y
Real button element. Busy sets aria-busy.

Anatomy
Two to four mutually exclusive options; one selected.
Rules
Selected state shows a shape or weight change, not colour alone. Used for a value choice (for example Cards or Rows in Settings), not for switching sections.

A11y

Filter chip

controltoggle
Anatomy
Label and a count.
Size
Visible height 30, hit area 44 through padding.
Rules
A pressed chip changes more than colour (a check mark or weight). A chip with a nonzero attention count may use the status role.
A11y
Toggle button with pressed state; group is labelled "Filter positions".

Text field

inputlabel above
Anatomy
Label above, field, helper or error line below. Optional trailing action (Paste, Clear).
Size
Height 52. Corners and border from tokens. Label is always visible; a placeholder is never the label.
States
Idle, focused, filled, looking up (spinner, status line), valid, invalid, disabled.
Rules
Error text says what is wrong and what to do, and is tied to the field. Inputs for addresses turn off autocorrect, autocapitalize and spellcheck.
A11y
Label for, aria-describedby for helper and error, aria-invalid, role alert for new errors.

Variants

Wallet row

listwallets
Anatomy
Monogram avatar, name, shortened address with positions count and value (both needs server field), trailing status or remove.
States
Active, paused (above plan limit: read-only, no alerts, shown muted with a word), removing (confirmation).

Tab bar and sidebar

navigationthree destinations
Destinations
Portfolio, Alerts, Settings. Same names and order everywhere.
Compact and medium
Bottom tab bar, labels always shown. One stack per tab.
Expanded
Sidebar with the same destinations; wallets appear as a filter list under Portfolio.
Rules

Bottom sheet

overlayscoped tasks only
Use
Add wallet, set alert, sign in, share options, and position details on phone. Not for navigation.
Anatomy
Handle, title, close button, content, primary action at the bottom.
Size
Detents at medium and large on phone; centred dialog or side sheet on wide layouts.
Rules
The handle is also a button. Dragging always has a Cancel or Done. The page behind is inert. Closing returns focus to the opener.
Motion
gentle in and out; scrim fades with fast.
