How to read the screens

Each screen is drawn at the compact and expanded layout classes (see Foundations). Medium follows compact with a wider margin, or expanded when there is room for two columns. Regions are listed in reading order, which is also focus order.

Scope. These are the MVP screens: Portfolio, Position, Add wallet, Wallets, Alerts, Alert settings, Settings, Sign in, Plans. Navigation between them is in the Navigation Map artifact. Data names are fields of the position model and the account endpoints.

Rule. Every number on a screen is derived on the server and formatted for display. A client places values and never computes them. This is why no screen below contains arithmetic.

Pending: all visual treatment. Screens must work with grey tokens and the system font.
