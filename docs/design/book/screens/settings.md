# Settings

Account, wallets, notifications, preferences, plan, about. A window on Mac.

## Regions, in order

| # | Region | Component | Shows |
|---|---|---|---|
| 1 | Account | List row | Signed in as, or Sign in; passkey management |
| 2 | Wallets and notifications | List rows | Open Wallets and Alert settings |
| 3 | Preferences | Rows with segmented control or menu | Positions view (Rows or Cards), appearance (system, light, dark) |
| 4 | Plan | List row | Current plan (plan name is a *needs server field*) and limits; opens Plans |
| 5 | About | List rows | Version, licence, source, privacy |

## States

| State | What changes |
|---|---|
| Guest | Account row says "Not signed in" and offers Sign in |
| Self-hosted instance | Instance address shown; sign-in uses the system browser |
| Mac | Opens as the Settings window (Command comma), grouped tabs |

## Navigation and focus

| Item | Rule |
|---|---|
| Focus | Title on arrival; the first row |
| View preference | Applies at once; no screen reload |
