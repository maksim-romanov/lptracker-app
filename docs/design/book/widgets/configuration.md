# Choosing what a widget shows

The person picks once when adding the widget.

| Option | Values | Default |
|---|---|---|
| Position | The worst position (*needs server field*), or a chosen position | The worst |
| Fill | Automatic, or one of the four Fills | Automatic |
| Wallet scope | All wallets, or one (only for the worst-position mode; the summary request takes the wallet scope and the server picks the worst) | All |

> **Rule.** Positions are a searchable entity so Siri, Spotlight and Shortcuts use the same list. Removing a watched position or wallet makes the widget fall back to the worst position (*needs server field*), then to the empty state.
