# Foundations

The base the rest of the book uses. It defines names, scales and rules. Colour Scheme values come from [ADR 0027](../../../decisions/0027-design-tokens.md); every other visual value is pending.

| Fixed here | Pending (design pass later) |
|---|---|
| Screens, regions and their order | Remaining colour values; Scheme tweaks |
| Component anatomy, states and behaviour | Weights other than bold display |
| Token names, layers and contexts | Corner shapes, borders, shadows, glass |
| Size rules, spacing scale, touch targets | Icons, illustration, logos beyond data |
| Data each element shows | Final copy and imagery |
| Accessibility and motion rules | Motion character beyond the shared tokens |

> **Placeholder policy.** See the [book README](../README.md#rules-for-an-agent-building-from-this-book).
