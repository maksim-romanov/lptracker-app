# Foundations

The base the rest of the book uses. It defines names, scales and rules. Colour Scheme values come from [ADR 0027](../../../decisions/0027-design-tokens.md); a value with no token yet comes from the approved prototype ([which source wins](../README.md#which-source-wins)).

| Fixed here | Not yet tokens: read from the approved prototype; if it does not show it, ask |
|---|---|
| Screens, regions and their order | Remaining colour values; Scheme tweaks |
| Component anatomy, states and behaviour | Type sizes per role |
| Token names, layers and contexts | Values marked design-pending in [colour](colour.md#m0-values) and [shape](shape-and-elevation.md); glass |
| Size rules, spacing scale, touch targets | Icons, illustration, logos beyond data |
| Data each element shows | Final copy and imagery |
| Accessibility and motion rules | Motion character beyond the shared tokens |

> **Placeholder policy.** See the [book README](../README.md#rules-for-an-agent-building-from-this-book).

The colours in the [wireframes](../visual/wireframes/foundations.html) are a documentation style, not a Scheme; take no value from them. The approved prototypes use the real Scheme.
