# Icons and imagery

Sizes and sources are fixed. Artwork is pending.

| Item | Rule |
|---|---|
| Icon grid | `icon.size.sm md lg` = 16, 20, 24. One stroke token `icon.stroke`. Icons with meaning have a text label or an accessible name. |
| Token logos | Served by hash from the server, size 64, 128 or 256. When missing, draw a monogram (up to 3 symbol characters) and the chain badge. Never show a broken image. |
| Token pair | Two logos overlapping by a quarter of their width, base token in front, quote token behind. Decorative; the pair name is text. |
| Chain and protocol marks | Small badge, 16. Name is always available as text. |
| Avatars | `avatar.size.sm md lg` = 28, 36, 44. Wallets use a generated monogram, not a photo. |
| Illustration | None in the base. Empty states use a simple outline made of the same shapes as the real content (a dashed outline card, a dashed bar). |
